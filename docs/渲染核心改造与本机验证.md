## 本机使用

已准备独立 Web Profile `mermaid-plus-local`，可执行：

```powershell
dsh --profile mermaid-plus-local --no-open --port 18732
```

若验证服务仍在运行，可直接打开 `http://127.0.0.1:18732/`。在该 Profile 打开已有包含 Mermaid 的会话，点击图表按钮；现有常用 Profile 未替换。

安装到其他 Profile 时使用其实际名称：

```powershell
dsh plugin --profile <名称> add D:\mycode\dsh-mermaid-plus\output\dsh-mermaid-plus-0.3.0-local.1.tgz
```

已有同名包时先在目标 Profile 移除旧包再添加本地包，并重启 DSH，避免 pnpm 缓存旧安装内容。
